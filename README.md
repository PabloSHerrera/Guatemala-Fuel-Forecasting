# Guatemala Fuel Forecasting

Time series analysis and forecasting of fuel data in Guatemala. The project explores historical series of fuel imports, consumption, and prices, fits ARIMA models, and selects the best-performing model to generate forecasts.

## Objectives

- Explore and characterize historical fuel series (trend, seasonality, stationarity)
- Fit and compare ARIMA models
- Select the best model based on evaluation metrics
- Generate forecasts with the selected model

## Repository Structure

| File | Description |
|---|---|
| `Análisis Exploratorio de Datos.ipynb` | Exploratory data analysis |
| `Analisis importaciones.ipynb` | Analysis of fuel imports |
| `Laboratorio 1.ipynb` | ARIMA modeling and forecasts |
| `IMPORTACION-HIDROCARBUROS-VOLUMEN...` | Fuel import volumes dataset |
| `Estadisticas.xlsx`, `estadisticas 2025.xlsx` | Additional statistical data |
| `Laboratorio 01 - Series de Tiempo.pdf` | Assignment specification (in Spanish) |

## Tech Stack

Python · pandas · statsmodels · Matplotlib · Jupyter Notebook

## How to Run

1. Clone the repository:

```bash
   git clone https://github.com/PabloSHerrera/Guatemala-Fuel-Forecasting.git
   cd Guatemala-Fuel-Forecasting
```
2. Open the notebooks and run them in the order shown above.
